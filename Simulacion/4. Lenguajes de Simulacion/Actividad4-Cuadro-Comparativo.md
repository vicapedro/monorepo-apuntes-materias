# Actividad 4: Cuadro Comparativo de Herramientas de Simulación

**Asignatura**: Simulación (SCD-1022) | Unidad 4  
**Modalidad**: Equipo (3-4 personas)  
**Duración**: 1 hora clase + 2 horas autónomas

---

## Objetivo

Analizar y comparar las principales herramientas de simulación (SimPy, AnyLogic, Arena, NetLogo, Vensim) en función de criterios técnicos y de aplicabilidad, para desarrollar criterio profesional en la selección de herramientas.

---

## Instrucciones

### Parte 1 — Investigación individual (30 min)

Cada integrante investiga en profundidad UNA herramienta:

| Integrante | Herramienta |
|-----------|-------------|
| A | SimPy (Python) |
| B | AnyLogic Personal Learning Edition |
| C | Arena / SIMIO |
| D | NetLogo |

Temas a investigar por herramienta:
1. Paradigma de simulación que soporta (DES, SD, MA o combinación)
2. Modelo de licenciamiento (gratuito, académico, comercial)
3. Lenguaje de programación interno o de scripting
4. Tipo de estadísticas y métricas que genera automáticamente
5. Un caso de uso real documentado (empresa, institución o investigación)

### Parte 2 — Cuadro comparativo en equipo (20 min)

Construir el cuadro comparativo usando la plantilla:

| Criterio | SimPy | AnyLogic PLE | Arena | NetLogo |
|----------|-------|-------------|-------|---------|
| Paradigmas soportados | | | | |
| Licencia | | | | |
| Lenguaje | | | | |
| Estadísticas automáticas | | | | |
| Integración Python | | | | |
| Curva de aprendizaje (1-5) | | | | |
| Adecuado para proyecto del curso | | | | |
| Caso de uso real documentado | | | | |

### Parte 3 — Presentación y defensa (10 min por equipo)

Presentar el cuadro comparativo y responder:
1. ¿Qué herramienta elegiría para el Proyecto Integrador de la Unidad 5 y por qué?
2. ¿Qué herramienta es más usada en la industria para el tipo de sistema de su proyecto?
3. ¿Qué limitación de SimPy los llevaría a preferir AnyLogic en un proyecto real?

---

## Entregables

- Cuadro comparativo en formato tabla (Markdown o PDF)
- Justificación escrita (1 párrafo) de la selección de herramienta para el proyecto final

**Ponderación**: 15% de la Unidad 4 (evaluado con Lista de Cotejo A4)
