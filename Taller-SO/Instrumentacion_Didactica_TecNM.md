## 🎯 Caracterización de la asignatura

**Administrar sistemas operativos mediante comandos, configuraciones y herramientas especializadas para garantizar la operación eficiente, segura y confiable de servicios en entornos empresariales, considerando las reglas de negocio y los estándares de la industria.**

Esta asignatura proporciona las competencias esenciales para la administración profesional de sistemas operativos, integrando conocimientos de arquitectura de computadoras, redes y seguridad informática. El enfoque práctico prepara a los estudiantes para enfrentar los retos tecnológicos actuales en la gestión de infraestructura TI empresarial.

---

## 💡 Intención didáctica

La asignatura **Taller de Sistemas Operativos** se fundamenta en el desarrollo de competencias prácticas para la administración profesional de sistemas operativos en entornos empresariales. Su diseño curricular responde a la creciente demanda de especialistas en infraestructura TI capaces de gestionar tanto sistemas propietarios como libres.

### Justificación Curricular

**Contexto Profesional**: En el ecosistema tecnológico actual, el 96.3% de los servidores web mundiales ejecutan sistemas Linux, mientras que Windows Server domina los entornos corporativos tradicionales. Esta dualidad tecnológica requiere profesionales versátiles capaces de administrar ambos paradigmas.

**Articulación Curricular**: La materia se articula verticalmente con:
- **Prerrequisitos**: Arquitectura de Computadoras, Redes de Computadoras
- **Corequisitos**: Administración de Bases de Datos, Programación Web
- **Posteriores**: Seguridad en Cómputo, Redes Avanzadas, DevOps

**Enfoque Metodológico**: Implementación de metodologías activas (ABP, AOP, ABR) que simulan escenarios empresariales reales, preparando a los estudiantes para la transición académico-profesional.

## Unidad 1: Introducción a Sistemas Operativos

### 🎯 Competencia

**SCB-1025.1** Analizar la clasificación, estructuras y funciones de los sistemas operativos para comprender sus fundamentos arquitectónicos y operacionales

### 📋 Temas y Subtemas

1.1 **Clasificación de Sistemas Operativos**
   - Por número de usuarios (monousuario, multiusuario)  
   - Por número de tareas (monotarea, multitarea)
   - Por ubicación (centralizados, distribuidos)

1.2 **Estructuras de Sistemas Operativos**
   - Estructura monolítica
   - Estructura por capas (layered)
   - Estructura microkernel
   - Estructura híbrida  
   - Estructura de módulos

1.3 **Virtualización**
   - Conceptos fundamentales de virtualización
   - Tipos de virtualización (completa, para-virtualización, contenedores)
   - Hypervisors tipo 1 y tipo 2
   - Ventajas y aplicaciones empresariales

### 👨‍🎓 Actividades de aprendizaje

- Investigar y comparar arquitecturas de SO actuales mediante análisis comparativo
- Implementar laboratorio de virtualización con múltiples SO para análisis práctico
- Desarrollar casos de estudio sobre selección de arquitecturas para diferentes contextos empresariales

### 👨‍🏫 Actividades de enseñanza

- Exposición magistral de conceptos fundamentales con demos interactivas
- Facilitación de discusiones grupales sobre ventajas/desventajas de cada estructura
- Supervisión de laboratorios prácticos con retroalimentación continua

## Unidad 2: Administración de Sistemas Operativos Propietarios

### 🎯 Competencia

**SCB-1025.2** Administrar sistemas operativos propietarios mediante herramientas gráficas y de línea de comandos para garantizar la operación eficiente de servicios empresariales

### 📋 Temas y Subtemas

2.1 **Características y Análisis de los Sistemas Operativos Propietarios**
   - Arquitectura de Windows Server
   - Ediciones y características principales
   - Modelos de licenciamiento

2.2 **Requerimientos de instalación**
   - Hardware y software requerido
   - Planificación de la instalación
   - Configuración inicial del sistema

2.3 **Configuración Básica**
   - Configuración de red y dominio
   - Administración de usuarios y grupos
   - Configuración de servicios básicos

2.4 **Comandos Básicos y Aplicaciones**
   - PowerShell y CMD
   - Herramientas de administración gráfica
   - Remote Administration Tools

2.5 **Administración del Sistema**
   - Active Directory y Group Policy
   - Monitorización y logs del sistema
   - Backup y recuperación
   - Administración de discos y file systems

### 👨‍🎓 Actividades de aprendizaje

- Implementar laboratorio de red Windows Server con múltiples roles y servicios
- Desarrollar scripts PowerShell para automatización de tareas administrativas
- Configurar políticas de seguridad y Group Policy Objects (GPO)

### 👨‍🏫 Actividades de enseñanza

- Demostración de instalación y configuración en laboratorio
- Facilitación de resolución de problemas en equipos colaborativos
- Tutoría personalizada en configuraciones avanzadas

## Unidad 3: Administración de Sistemas Operativos Libres

### 🎯 Competencia

**SCB-1025.3** Administrar sistemas operativos libres mediante comandos, configuraciones y herramientas especializadas para garantizar la operación eficiente, segura y confiable de servicios en entornos empresariales

### 📋 Temas y Subtemas

3.1 **Características y Análisis de los Sistemas Operativos Libres**
   - Filosofía del software libre y Open Source
   - Distribuciones principales: Debian, Ubuntu, CentOS, Arch
   - Modelos de soporte y comunidad

3.2 **Requerimientos de instalación**
   - Hardware compatible y optimizado
   - Métodos de instalación (física, virtual, red)
   - Particionamiento y file systems

3.3 **Configuración Básica**
   - Configuración de red y seguridad
   - Gestión de usuarios y grupos
   - Servicios del sistema (systemd)

3.4 **Comandos Básicos y aplicaciones**
   - Shell scripting (bash)
   - Gestión de archivos y permisos
   - Instalación de software (apt, yum, dnf)

3.5 **Administración del Sistema**
   - Monitorización de recursos y rendimiento
   - Configuración de servicios de red
   - Backup automático y recuperación
   - Hardening y seguridad

### 👨‍🎓 Actividades de aprendizaje

- Implementar servidor Linux completo con servicios LAMP/LEMP
- Desarrollar solución de migración empresarial de Windows a Linux
- Crear sistema de monitorización y alertas automatizado

### 👨‍🏫 Actividades de enseñanza

- Aprendizaje Basado en Problemas: "Migración EcoTech Solutions"
- Coaching técnico durante implementación de proyectos
- Evaluación continua con peer programming

## Unidad 4: Interoperabilidad entre Sistemas Operativos

### 🎯 Competencia

**SCB-1025.4** Implementar soluciones de interoperabilidad entre diferentes sistemas operativos para facilitar la integración y comunicación en entornos heterogéneos

### 📋 Temas y Subtemas

4.1 **Protocolos de Comunicación**
   - SMB/CIFS para compartición de archivos
   - NFS para sistemas Unix/Linux
   - SSH y protocolos seguros

4.2 **Integración de Servicios**
   - Samba como puente Windows-Linux
   - LDAP para autenticación centralizada
   - Sincronización de usuarios y grupos

4.3 **Virtualización y Contenedores**
   - Orquestación de contenedores multi-SO
   - Migración de máquinas virtuales
   - Cloud híbrido (Windows/Linux)

4.4 **Automatización Cross-Platform**
   - Ansible para gestión unificada
   - Scripts multiplataforma
   - Herramientas de monitorización unificada

### 👨‍🎓 Actividades de aprendizaje

- Diseñar infraestructura híbrida Windows-Linux funcional
- Implementar sistema de autenticación centralizada multi-SO
- Desarrollar herramientas de administración cross-platform

### 👨‍🏫 Actividades de enseñanza

- Estudio de Casos empresariales de integración compleja
- Laboratorio colaborativo de resolución de problemas de interoperabilidad
- Proyecto integrador con evaluación por pares
