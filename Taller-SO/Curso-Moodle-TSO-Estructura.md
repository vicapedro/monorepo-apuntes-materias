## 🎯 ESTRUCTURA DEL CURSO

### SEMANA 0: BIENVENIDA E INTRODUCCIÓN
**Actividades:**
- Presentación del curso y metodología
- Examen diagnóstico
- Configuración de entorno virtual de laboratorio
- Foro de presentación

### UNIDAD 1: INTRODUCCIÓN A SISTEMAS OPERATIVOS (Semanas 1-4)
**Competencia**: Analizar la clasificación, estructuras y funciones de los sistemas operativos

### UNIDAD 2: WINDOWS SERVER (Semanas 5-8)
**Competencia**: Instalar, configurar y administrar sistemas operativos propietarios

### UNIDAD 3: LINUX (Semanas 9-12)
**Competencia**: Instalar, configurar y administrar sistemas operativos de código abierto

### UNIDAD 4: INTEROPERABILIDAD (Semanas 13-16)
**Competencia**: Implementar comunicación y recursos compartidos entre sistemas operativos

## 🔧 CONFIGURACIONES TÉCNICAS RECOMENDADAS

### Configuración Moodle
```php
// Configuraciones específicas para TSO
$CFG->maxbytes = 2147483648; // 2GB para uploads de VMs
$CFG->forum_maxbytes = 524288000; // 500MB para compartir archivos
$CFG->assignment_maxbytes = 1073741824; // 1GB para proyectos
```

### Plugins Recomendados
- **H5P**: Para contenido interactivo
- **BigBlueButton**: Para sesiones de laboratorio en vivo
- **Plagiarism**: Para verificar originalidad de reportes
- **Learning Analytics**: Para seguimiento del progreso

### Backup y Seguridad
- Respaldos automáticos semanales
- Autenticación por LDAP/SSO
- Roles específicos: Estudiante, Profesor, Asistente de Laboratorio
- Acceso por grupos para laboratorios
