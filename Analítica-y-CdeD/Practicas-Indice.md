## Recursos Complementarios

### Software Requerido
- **Anaconda Distribution**: Plataforma principal con Python 3.9+
- **Jupyter Notebooks**: Entorno de desarrollo interactivo
- **Bibliotecas principales**: NumPy, Pandas, Matplotlib, Seaborn

### Datasets de Práctica
- Datos sintéticos generados en cada práctica
- Ejemplos empresariales: ventas, inventarios, empleados, finanzas
- Casos de uso reales adaptados para aprendizaje

### Metodología de Trabajo
1. **Preparación**: Leer objetivos y competencias antes de iniciar
2. **Desarrollo**: Seguir instrucciones paso a paso con experimentación
3. **Ejercicios**: Completar todos los ejercicios propuestos
4. **Reflexión**: Documentar aprendizajes y dificultades encontradas
5. **Aplicación**: Intentar variaciones y casos personales

## Evaluación y Portafolio

### Criterios de Evaluación
Cada práctica será evaluada considerando:
- **Funcionalidad**: El código ejecuta correctamente
- **Comprensión**: Dominio de conceptos aplicados
- **Documentación**: Código comentado y explicado
- **Aplicación**: Capacidad de adaptar a nuevos casos
- **Presentación**: Organización y claridad en notebooks

### Estructura del Portafolio
Para cada práctica incluir:
1. **Notebook completado** con todos los ejercicios
2. **Capturas de pantalla** de resultados clave
3. **Reflexión personal** sobre aprendizajes (200-300 palabras)
4. **Código adicional** con experimentación propia (opcional)
5. **Referencias consultadas** durante la práctica

### Rúbrica General

| Criterio | Excelente (3) | Bueno (2) | Aceptable (1) | Insuficiente (0) |
|----------|---------------|-----------|---------------|------------------|
| **Completitud** | Todos los ejercicios completados y funcionando | Mayoría de ejercicios completados | Algunos ejercicios completados | Pocos o ningún ejercicio completado |
| **Calidad técnica** | Código eficiente, elegante y bien estructurado | Código funcional con buena estructura | Código funcional básico | Código con errores o mal estructurado |
| **Documentación** | Comentarios claros y explicaciones detalladas | Comentarios adecuados | Comentarios básicos | Sin comentarios o inadecuados |
| **Aplicación práctica** | Adaptaciones creativas y casos adicionales | Algunas adaptaciones propias | Aplicación directa de ejemplos | No muestra aplicación práctica |
| **Comprensión** | Dominio completo de conceptos y técnicas | Buena comprensión general | Comprensión básica | Comprensión insuficiente |

## Consejos para el Éxito

### Durante el Desarrollo
- **Experimentar activamente**: No solo copiar código, sino probarlo y modificarlo
- **Buscar ayuda**: Usar documentación oficial y recursos en línea
- **Trabajar incrementalmente**: Completar secciones paso a paso
- **Guardar frecuentemente**: Versionar notebooks para evitar pérdidas

### Para el Aprendizaje Efectivo
- **Conectar con experiencias previas**: Relacionar con conocimientos de otras materias
- **Practicar regularmente**: Dedicar tiempo consistente en lugar de sesiones largas esporádicas
- **Formar grupos de estudio**: Discutir conceptos y resolver problemas en equipo
- **Buscar aplicaciones reales**: Pensar en cómo usar estas herramientas en proyectos futuros

### Preparación para Unidades Siguientes
- **Dominar los fundamentos**: Cada práctica es base para las siguientes
- **Mantener notas organizadas**: Crear referencia personal de funciones y técnicas
- **Practicar más allá de los ejercicios**: Buscar datasets adicionales para experimentar
- **Desarrollar intuición de datos**: Aprender a "leer" los datos antes de analizarlos

¡Buena suerte con tus prácticas! Recuerda que el dominio de estas herramientas fundamentales es la clave para el éxito en analítica y ciencia de datos.
