# Introducción a la Unidad 1: Funciones de la Administración de Redes
La administración de redes es el conjunto de procesos, técnicas y herramientas que permiten supervisar, controlar y optimizar una infraestructura de comunicación para que opere de forma continua, eficiente y segura. En esta unidad se introduce el modelo **FCAPS**, uno de los marcos de referencia más utilizados para organizar las tareas del administrador de red.

El modelo **FCAPS** surge en el contexto de la gestión de redes de telecomunicaciones estandarizada por la **ITU-T** (Unión Internacional de Telecomunicaciones), especialmente a partir de los lineamientos de **TMN** (Telecommunications Management Network). Su objetivo fue clasificar de manera clara las funciones de gestión para facilitar la operación de redes cada vez más complejas.

**FCAPS** representa cinco áreas clave:

**F — Fallas (Fault Management):** Detectar, aislar, registrar y corregir fallas para reducir interrupciones.

**C — Configuración (Configuration Management):** Administrar cambios, inventario y parámetros de dispositivos y servicios.

**A — Contabilidad (Accounting Management):** Medir y registrar el uso de recursos de red para control de costos y asignación.

**P — Desempeño (Performance Management):** Monitorear métricas (latencia, ancho de banda, pérdida, uso) para mantener calidad de servicio.

**S — Seguridad (Security Management):** Proteger la red mediante controles de acceso, políticas, auditoría y respuesta ante incidentes.

En síntesis, **FCAPS** permite estudiar la administración de redes de forma estructurada, integrando operación técnica, control administrativo y protección de la infraestructura.
