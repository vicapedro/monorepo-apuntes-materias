## 🧩 Actividad de Repaso: Clases de Direccionamiento IP

### 🎯 Propósito
Reforzar el conocimiento sobre las clases de direcciones IP, sus rangos y aplicaciones, como base para el diseño lógico de redes LAN y WAN.


### 📚 Instrucciones
1. **Formen equipos de 3 a 4 integrantes.**
2. **Investiguen** las características de las clases de IP (A, B, C, D, E), incluyendo:
   - Rango de direcciones
   - Uso típico
   - Número de hosts por red
   - Ejemplos de aplicación
3. **Elaboren una tabla comparativa** en formato digital (Canva, Word, Excel, Notion, etc.).
4. **Resuelvan los siguientes ejercicios**:
   - Identifiquen la clase de las siguientes direcciones IP:
     - `10.10.0.1`
     - `172.18.5.4`
     - `192.168.1.100`
     - `224.0.0.5`
     - `240.0.0.1`
   - ¿Qué clase de IP se utiliza para multicast?
   - ¿Qué clase está reservada para investigación?
5. **Presenten sus resultados** en clase o en Teams/Moodle, explicando brevemente cada punto.

### 💡 Sugerencia para el docente

Puedes iniciar la actividad con una pregunta detonadora como:
> “¿Por qué no todas las direcciones IP son iguales? ¿Qué pasaría si usamos una IP clase A en una red doméstica?”

Esto ayudará a captar la atención y conectar con la etapa 1 del Modelo de Gagné.
