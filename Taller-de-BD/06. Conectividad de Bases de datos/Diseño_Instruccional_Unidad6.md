# Diseño Instruccional - Unidad 6: Conectividad de Bases de Datos
**Taller de Base de Datos | Ingeniería en Sistemas Computacionales**

---

## 📋 Datos de la Unidad
- **Unidad**: 6 - Conectividad de Bases de Datos
- **Duración**: 2 semanas
- **Horas**: 16 horas (4 horas teoría, 0 horas práctica, 12 horas trabajo autónomo)
- **Modalidad**: Presencial con soporte en Moodle y Teams
- **Prerrequisitos**: Unidades 1-5 completadas

---

## 🎯 Competencia Específica de la Unidad
**Establecer conexiones entre SGBD y lenguajes de programación mediante cadenas de conexión y protocolos de comunicación para integrar bases de datos en soluciones de software multiplataforma.**

---

## 📚 Objetivos de Aprendizaje
Al finalizar esta unidad, el estudiante será capaz de:

- ✅ **Configurar conectividad** entre SGBD y aplicaciones usando ODBC, ADO.NET y JDBC
- ✅ **Implementar conexiones** desde lenguajes huésped (Python, Java, C#, JavaScript)
- ✅ **Desarrollar aplicaciones** web y móviles conectadas a bases de datos
- ✅ **Crear APIs REST** para acceso a datos desde múltiples plataformas
- ✅ **Optimizar rendimiento** de conexiones y gestionar pools de conexiones
- ✅ **Implementar seguridad** en conexiones de bases de datos

## 🎓 Metodología Activa Seleccionada

### **🤝 Aprendizaje Cooperativo - Equipos Especializados**

**Justificación de selección**: La conectividad de bases de datos requiere competencias diversas en múltiples tecnologías. El aprendizaje cooperativo permite que estudiantes se especialicen en áreas específicas mientras colaboran en un proyecto integrador común.

#### **Estructura de Equipos**:

1. **🔧 Backend Team**: 
   - **Especialización**: Python (Django/FastAPI), Java (Spring Boot)
   - **Responsabilidades**: APIs REST, lógica de negocio, seguridad
   - **Entregable**: Servicios web documentados y testeados

2. **🌐 Frontend Team**: 
   - **Especialización**: React, Vue.js, HTML5, CSS3
   - **Responsabilidades**: Interfaces de usuario, experiencia de usuario
   - **Entregable**: Aplicación web responsiva y funcional

3. **📱 Mobile Team**: 
   - **Especialización**: React Native, Flutter, desarrollo híbrido
   - **Responsabilidades**: Apps móviles, sincronización offline
   - **Entregable**: Aplicación móvil multiplataforma

4. **☁️ DevOps Team**: 
   - **Especialización**: Docker, cloud deployment, CI/CD
   - **Responsabilidades**: Infraestructura, despliegue, monitoreo
   - **Entregable**: Ambiente de producción automatizado

#### **Dinámicas de Colaboración**:
- **Daily standups** (10 min): Estado, blockers, planificación diaria
- **Sprint reviews** semanales: Demo de avances por equipo
- **Cross-team integration**: Sesiones de integración entre equipos
- **Retrospectivas**: Mejora continua del proceso colaborativo

## 🚀 Aplicación del Modelo de Gagné - 9 Eventos

### **1. 🎯 Ganar la Atención**
**Duración**: 15 minutos

**Actividad**: **"Demo Shock: WhatsApp vs Sistema Empresarial"**
- Mostrar conversación de WhatsApp funcionando en tiempo real
- Explicar la infraestructura de conectividad detrás (millones de conexiones simultáneas)
- Contrastar con sistema empresarial típico con problemas de conectividad
- **Pregunta provocadora**: *"¿Por qué WhatsApp nunca se desconecta pero los sistemas empresariales sí?"*

### **2. 📢 Informar Objetivos de Aprendizaje**
**Duración**: 10 minutos

**Actividad**: **Presentación Visual de Competencias**
- **Infografía interactiva** mostrando el ecosistema de conectividad
- **Mapa de ruta** del aprendizaje: ODBC → API → Apps
- **Casos de éxito**: Netflix, Uber, LinkedIn (arquitecturas de conectividad)
- **Expectativas claras** sobre productos finales

### **3. 🧠 Estimular Recuerdo de Conocimientos Previos**
**Duración**: 20 minutos

**Actividad**: **"Conectividad en tu Smartphone"**
- **Análisis grupal**: ¿Cuántas apps usan bases de datos en tu teléfono?
- **Demostración**: Abrir Instagram offline vs online
- **Discusión**: Patrones observados en apps que ya conocen
- **Conexión**: Relacionar con SQL y bases de datos vistas en unidades anteriores

### **4. 📚 Presentar Material de Estímulo**
**Duración**: 60 minutos

**Contenido Estructurado**:

#### **4.1 Fundamentos de Conectividad (20 min)**
- **ODBC**: Open Database Connectivity - Standard universal
- **JDBC**: Java Database Connectivity - Ecosistema Java
- **ADO.NET**: ActiveX Data Objects - Microsoft stack
- **Drivers nativos** vs **Drivers universales**

#### **4.2 Arquitecturas de Conexión (20 min)**
- **Connection strings**: Anatomía y configuración
- **Connection pooling**: Optimización de recursos
- **Patrones**: Repository, DAO, ORM
- **Seguridad**: Cifrado, autenticación, autorización

#### **4.3 Tecnologías por Plataforma (20 min)**
- **Web**: Node.js + Express, Python + Django, PHP + Laravel
- **Móvil**: React Native, Flutter, Xamarin
- **Desktop**: Electron, .NET, Qt
- **APIs**: REST, GraphQL, gRPC

### **5. 🎯 Proporcionar Orientación de Aprendizaje**

**Actividad**: **"Roadmap Personalizado por Equipo"**
