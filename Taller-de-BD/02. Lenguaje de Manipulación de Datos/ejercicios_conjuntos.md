## Ejercicios de Consultas SQL con Operadores de Conjuntos

### Instrucciones Generales

En el archivo adjunto se encuentra la base de datos necesaria para realizar los ejercicios. Descargue e importe el archivo a Microsoft SQL Server antes de comenzar.

**Entregable:** Archivo `.sql` con las consultas solicitadas.

---

### Ejercicios

Obtenga la siguiente información usando SQL con los operadores de conjuntos `EXCEPT`, `INTERSECT` y `UNION`:

1. **Clientes jóvenes de pizza supreme**  
    Nombre de las personas con edad menor que 40 años que **solamente** comen pizzas 'supreme'.

2. **Pizzerías premium**  
    Nombre de las pizzerías que **solamente** sirven pizzas con precio mayor que $10.

3. **Pizzerías para adultos**  
    Nombre de las pizzerías que son frecuentadas **solamente** por personas mayores de 18 años.

4. **Aficionados mayores al pepperoni**  
    Mostrar el nombre de las personas con la **edad mayor** que comen pizza de pepperoni.

5. **Cliente más joven de Chicago Pizza**  
    Mostrar el nombre de las personas con la **edad menor** que come en la pizzería 'Chicago Pizza'.

6. **Pizzas premium o compartidas**  
    Mostrar las pizzas cuyo costo es mayor que $10 **o** que comen en común Eli y Gus.

7. **Personas que evitan el queso**  
    Mostrar los nombres de las personas que **no** comen pizzas de 'cheese'.

8. **Gustos compartidos premium**  
    Mostrar las pizzas cuyo costo es mayor que $10 **y** que comen Eli **y** Gus.

9. **Pizzerías exclusivas para mayores**  
    Mostrar las pizzerías que **solamente** sirven a personas mayores de 30 años.

10. **Pizza más económica**  
     Mostrar el nombre de la pizza más barata.

---

### 💡 Consideraciones

- Utilice **comentarios** para identificar cada consulta en su archivo SQL.
- Asegúrese de que las consultas sean **eficientes** y utilicen los operadores de conjuntos apropiados.
- Verifique la **sintaxis correcta** de Microsoft SQL Server.
- Pruebe cada consulta antes de entregar el archivo final.
