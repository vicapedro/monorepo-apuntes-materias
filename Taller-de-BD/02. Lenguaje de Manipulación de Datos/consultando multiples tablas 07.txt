Slide 5:
Outer joins
SQL server, soporta tres tipos de outer joins: left, right and full.
Left outer join.- El resultado del select, incluye todos los renglones de la tabla referenciada a la izquierda. Los únicos renglones que se muestran de la tabla de la derecha son los que cumplen la condición.
Right outer join.- Igual que el left pero se aplica para la tabla de la derecha.
Full outer join.- muestra los datos de las dos tablas aun sin correspondencia. Los valores de los campos que no cumplen con la condición se muestran con nulos.

Slide 10:
Combinando múltiples resultados
Usa el operador UNION para crear un resultado de múltiples consultas. Elimina los duplicados.
Cada consulta debe tener:
tipos de datos similares
mismo número de columnas 
El mismo orden de las columnas

USE northwind
SELECT name = (firstname + ' ' + lastname), 
              city, postalcode
FROM employees
UNION
SELECT companyname, city, postalcode
FROM customers

Slide 11:
Combinando múltiples resultados
Usa el operador UNION ALL para crear un resultado de múltiples consultas.
Se utiliza igual que UNION, sólo que no elimina tuplas repetidas.


Slide 12:
Creando una tabla a partir de un conjunto de resultados
Usando la instrucción SELECT INTO 
Requiere nombre de tablas únicos
Sp-dboption db, “select/bulkcopy”, true
USE northwind
SELECT productname AS products,
       unitprice AS price,
       (unitprice * 1.1) AS tax
INTO #pricetable
FROM products
