Slide 9:
Predicado LIKE
También se pueden seleccionar registros basados en un conjunto de caracteres. Una instrucción SELECT  que contiene un predicado LIKE en la cláusula WHERE, el predicado LIKE contiene porciones de caracteres que se  comparan con otra porción de caracteres.

Slide 10:
Caracteres de control del LIKE
	El predicado LIKE usa uno o mas de los caracteres de 
control que se muestran a continuación:




% 	Cualquier string de uno o mas caracteres
_	Un carácter simple
[ ] 	Cualquier carácter simple dentro del conjunto de 
	valores en el conjunto.

Ejemplos del LIKE

LIKE ‘[CK]%´ todos los nombres que que inicien con C o con K.

Slide 28:
Borrando renglones
DELETE  
Se usa para eliminar uno o más renglones
Siempre incluye una cláusula Where
Cada renglón borrado es insertado en el Log
TRUNCATE TABLE Statement
Se usa para borrar todos los renglones de una tabla
Es más rápida que un DELETE.

Slide 29:
Ejemplo del DELETE 
USE pubs
DELETE FROM authors

Slide 30:
Actualización de tablas 


La instrucción UPDATE cambia los datos existentes en una tabla. Se puede utilizar la cláusula UPDATE para actualizar un renglón, un grupo de renglones o toda la tabla.La cláusula UPDATE opera sobre una sola tabla.


Slide 31:
Ejemplo
USE pubs
UPDATE discount 
SET discount=discount+.10
WHERE lowqty>=100


Slide 32:
Ejemplo

SET phone=‘203 987-6543’
WHERE au_id=‘123-45-6789’

Actualizando renglones
