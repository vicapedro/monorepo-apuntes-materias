## 2. Presentación

### 🎯 Caracterización de la Asignatura

Esta asignatura aporta al perfil del **Ingeniero en Sistemas Computacionales** las competencias para:

- ✅ **Implementar bases de datos** y apoyar la toma de decisiones
- ✅ **Cumplir normas vigentes** de manejo y seguridad de la información
- ✅ **Utilizar tecnologías emergentes** para integrar soluciones computacionales
- ✅ **Integrar diferentes plataformas** y/o dispositivos
- ✅ **Considerar aspectos** legales, éticos, sociales y de desarrollo sustentable

#### 📋 Contenido Principal

La asignatura consiste en el uso de:
- **Lenguaje de Definición de Datos (DDL)**
- **Lenguaje de Manipulación de Datos (DML)**
- **Control de acceso**
- **Transacciones**
- **SQL procedural**
- **Conectividad de base de datos**

#### 🔗 Articulación Curricular

**Materias Prerequisito:**
- 📚 Fundamentos de Bases de Datos
- 💻 Tópicos Avanzados de Programación

**Competencias previas necesarias:**
- Diseño y modelado
- Manejo de SQL
- Aspectos de conectividad entre bases de datos y lenguajes huésped

**Aporta competencias a:**
- 🗄️ Administración de Bases de Datos
- 🛠️ Ingeniería de Software
- 📊 Gestión de Proyectos de Software
- 🌐 Programación Web

### 📖 Intención Didáctica

La estructura temática sigue una progresión lógica:

#### **Tema 1: Instalación y DDL**
- Instalación del motor SGBD y herramientas de administración
- Creación y modificación de esquemas de bases de datos
- Aplicación del lenguaje de definición de datos
- Elementos de integridad

#### **Tema 2: Manipulación de Datos**
- Prácticas de manipulación de registros
- Recuperación de datos
- Manejo de vistas

#### **Tema 3: Control de Acceso**
- Asignación de roles y cuentas de usuarios
- Gestión de privilegios sobre SGBD

#### **Tema 4: Concurrencia**
- Operación multiusuario de bases de datos
- Acceso concurrente
- Control de transacciones
- Anomalías derivadas de la concurrencia
- Mecanismos para tratar la concurrencia

#### **Tema 5: SQL Procedural**
- Creación y llamada de Stored Procedures
- Functions y Triggers
- Automatización de procesos para garantizar consistencia e integridad
- Independencia de lenguajes de programación

#### **Tema 6: Conectividad**
- Conectividad con distintas tecnologías
- Integración con diversos lenguajes de programación

### 🎯 Proyecto Integrador

Se realizará un **proyecto integrador** que:
- ✅ Involucre de manera práctica todos los temas del curso
- ✅ Incorpore competencias específicas para otras asignaturas
- ✅ Requiera implementación profesional de bases de datos
- ✅ Incluya casos de estudio reales con múltiples escenarios

### 🔧 Enfoque Metodológico

**Características del enfoque:**
- 💻 **100% práctico**: Todos los temas se desarrollan con prácticas específicas
- 🎯 **Aplicación directa**: Manipulación directa de esquemas e instancias
- 🔒 **Seguridad integrada**: Niveles de seguridad en el acceso
- 🛠️ **Herramientas actuales**: Consolas y herramientas comerciales vigentes
- 🌍 **Casos reales**: Implementación de casos de estudio auténticos
- 📈 **Aprendizaje significativo**: Desarrollo efectivo de competencias

## 7. Actividades de Aprendizaje por Tema

### 📋 TEMA 1: Lenguaje de Definición de Datos

#### **Competencias**
- ⚙️ **Utiliza procedimientos de instalación** de SGBD para diversas plataformas
- 🏗️ **Construye esquemas de base de datos** para proyectar necesidades del cliente basándose en las reglas sintácticas del DDL

#### **Actividades de Aprendizaje**
- 🔽 Realizar búsqueda, descarga e instalación de un SGBD
- 📄 Elaborar reporte de instalación
- 🔍 Interpretar modelos de bases de datos
- 🏗️ Crear esquemas de base de datos a partir de especificaciones definidas
- 🔧 Modificar esquemas para aplicar restricciones o reflejar cambios de diseño
- 📋 Elaborar reporte de prácticas

---

### 🔄 TEMA 2: Lenguaje de Manipulación de Datos

#### **Competencias**
- 💻 **Construye expresiones en SQL** para resolver necesidades de recuperación de información con las reglas sintácticas del DML

#### **Actividades de Aprendizaje**
- ➕ Realizar operaciones de inserción, actualización y eliminación de registros
- ❓ Ejercitar la creación de consultas mediante un problemario
- 🔍 Analizar requerimientos de información y determinar soluciones
- 🏗️ Construir consultas SQL que resuelven problemas específicos
- 📋 Elaborar reportes de las prácticas

---

### 🔒 TEMA 3: Control de Acceso

#### **Competencias**
- 🛡️ **Implementar mecanismos de seguridad básicos** para el acceso a datos mediante otorgamiento o denegación de privilegios

#### **Actividades de Aprendizaje**
- 📖 Análisis de políticas de seguridad
- 👥 Creación de mecanismos de seguridad mediante usuarios y roles
- 🔑 Aplicar el concepto de autorizaciones a objetos de la base de datos
- 🏋️ Elaborar ejercicios con incorporación de actividades previas
- 📋 Elaborar reportes de resultados

---

### ⚡ TEMA 4: Concurrencia

#### **Competencias**
- 🔄 **Controla la concurrencia** de la base de datos para disminuir problemas de desempeño y/o consistencia

#### **Actividades de Aprendizaje**
- 🎭 Crear escenarios para generar y analizar problemas de concurrencia
- ⚙️ Configurar el SGBD en modo transaccional
- 🧪 Realizar ejercicios con conceptos de granularidad, grados de consistencia, niveles de aislamiento
- 📊 Evaluar cómo afecta al desempeño y consistencia el nivel de aislamiento de la transacción
- 📋 Elaborar reportes de resultados

---

### 🔧 TEMA 5: SQL Procedural

#### **Competencias**
- ⚙️ **Aplicar SQL procedural** para automatizar reglas de negocio y garantizar integridad, consistencia y seguridad mediante stored procedures, functions y triggers

#### **Actividades de Aprendizaje**
- 💪 Realizar ejercicios que refuercen la sintaxis y estructura de stored procedures, functions y triggers
- 🎯 Resolver problemas que requieran el uso de estos elementos
- 🏢 Implementar reglas de negocio y/o auditoría utilizando disparadores
- 📋 Elaborar reportes de resultados

---

### 🌐 TEMA 6: Conectividad de Bases de Datos

#### **Competencias**
- 🔗 **Establecer conexiones** entre el SGBD y algún lenguaje de programación mediante cadenas de conexión y/o protocolos de comunicación

#### **Actividades de Aprendizaje**
- 🔽 Buscar, seleccionar, descargar e instalar diferentes librerías de conectividad
- 💻 Realizar ejercicios de conectividad desde lenguajes huésped o anfitriones
- 🌐 Realizar ejercicios que utilicen infraestructura de red para establecer conexiones
- 📋 Elaborar reportes de prácticas

## 8. Prácticas

### 📝 Distribución de Prácticas por Tema

#### **🔧 Tema 1 - DDL**
- ⚙️ **Instalación de un SGBD**
- 🏗️ **Creación y modificación de esquemas** de base de datos

#### **📊 Tema 2 - DML**
- ➕ **Manipulación de registros**
- ❓ **Creación de consultas** mediante problemario
- 🎯 **Solución de problemas** mediante instrucciones DML

#### **🔒 Tema 3 - Seguridad**
- 👥 **Mecanismos de seguridad**: creación de usuarios y roles
- 🔑 **Autorizaciones** a objetos de la base de datos

#### **⚡ Tema 4 - Concurrencia**
- 🔍 **Análisis de problemas** de la concurrencia
- 🧪 **Aplicación de conceptos** de granularidad, grados de consistencia, niveles de aislamiento
- 📊 **Reporte de desempeño y consistencia** de una base de datos referente al nivel de aislamiento

#### **🔧 Tema 5 - SQL Procedural**
- 💻 **Problemario** acerca de Stored procedures, functions y triggers
- 🏢 **Implementación de reglas de negocio** y/o auditoría utilizando disparadores

#### **🌐 Tema 6 - Conectividad**
- 📦 **Instalación de librerías** de conectividad para distintos SGBD
- 💻 **Conectividad desde lenguajes** huésped y/o anfitriones
- 🌐 **Conectividad mediante protocolos** de comunicación

## 9. Proyecto de Asignatura

### 🎯 Objetivo

Demostrar el **desarrollo y alcance de la(s) competencia(s)** de la asignatura.

### 📋 Fases del Proyecto

#### **1. 📚 Fundamentación**
- **Marco referencial**: teórico, conceptual, contextual, legal
- **Diagnóstico**: comprensión de la realidad o situación objeto de estudio
- **Definición**: proceso de intervención o diseño de un modelo

#### **2. 🗓️ Planeación**
- **Diseño del proyecto** por parte de los estudiantes con asesoría del docente
- **Planificación del proceso**: intervención empresarial, social o comunitario
- **Definición de actividades**: recursos requeridos y cronograma de trabajo

#### **3. ⚡ Ejecución**
- **Desarrollo de la planeación** realizada por los estudiantes
- **Intervención**: social, empresarial, o construcción del modelo propuesto
- **Fase de mayor duración** que implica el desempeño de competencias genéricas y específicas

#### **4. 📊 Evaluación**
- **Juicio de valor** en el contexto laboral-profesional, social e investigativo
- **Reconocimiento de logros** y aspectos a mejorar
- **Evaluación para la mejora continua**
- **Desarrollo del pensamiento crítico y reflexivo**
